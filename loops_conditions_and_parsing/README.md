# Shell, Loops, Conditions and Parsing

Bash scripting fundamentals: for, while and until loops, if/elif/else and
case conditionals, file test operators, and log parsing with awk.

## Files

- `1-for_best_school` - prints "Best School" 10 times using a for loop
- `2-while_best_school` - prints "Best School" 10 times using a while loop
- `3-until_best_school` - prints "Best School" 10 times using an until loop
- `4-if_9_say_hi` - prints "Best School" 10 times, "Hi" after the 9th
- `5-4_bad_luck_8_is_your_chance` - if/elif/else with bad luck / good luck
- `6-superstitious_numbers` - case statement with superstitious numbers
- `7-clock` - nested while loops to display hours and minutes
- `8-for_ls` - lists files, showing only the part after the first dash
- `9-to_file_or_not_to_file` - checks existence, emptiness and type of a file
- `10-fizzbuzz` - classic FizzBuzz from 1 to 100
- `11-read_and_cut` - extracts username, uid and home dir from /etc/passwd
- `12-tell_the_story_of_passwd` - tells a story for each /etc/passwd entry
- `13-lets_parse_apache_logs` - parses apache log for IP and HTTP code
- `14-dig_the-data` - groups and sorts apache log data by occurrence
